# Competitive_Programmers_Vault
This repo holds my solutions to the problems I've solved while practicing competitive programming. Most are in C++ and use the same template I use in contests.

Each solution is the code I submitted, so you'll see my habits and the occasional rough edge. If you're stuck on a problem, feel free to read through them, but try it yourself first.

Pull requests and issues are welcome if you spot a bug or know a faster approach.
